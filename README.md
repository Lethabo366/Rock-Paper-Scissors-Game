# 🤖 Rock, Paper, Scissors: Evil AI Challenge

An evil AI has challenged you! Can you defeat it before it wins?

This is a JavaScript-based Rock, Paper, Scissors game where players compete against an AI opponent. The goal is to be the first to score 3 points while making strategic choices to defeat the AI.

## 🎮 Game Rules

- **Rock beats Scissors.**
- **Paper beats Rock.**
- **Scissors beats Paper.**
- The first player to score **3 points** wins the game.
- Draws do not award points to either player.
- Invalid choices do not count as a round.
- Press **Cancel** on the prompt to quit the game safely.

## 🕹️ How to Play

1. Open the game in your browser.
2. When prompted, enter one of the following choices:
   - `Rock`
   - `Paper`
   - `Scissors`
3. The AI will make its choice.
4. View the round results to see who wins the round.
5. Continue playing until either you or the AI reaches 3 points.

## 📊 Results and Feedback

The game displays the results of each round in two places:

- **Browser alerts:** Display the outcome of each round.
- **Browser console:** Logs round results and other relevant game information.

## 🖥️ How to Open the Browser Console

To view the game logs in your browser:

**On Windows:**
1. Open the game in your browser.
2. Press `F12` or `Ctrl + Shift + J`.
3. Select the **Console** tab if it is not already selected.

The console allows you to inspect the results printed by the game as you play.

## 🚀 Getting Started

### Prerequisites

- A modern web browser, such as Google Chrome or Microsoft Edge.
- A code editor, such as Visual Studio Code, if you want to inspect or modify the source code.

### Running the Game

1. Clone or download the project repository.
2. Open the project folder in your code editor.
3. Locate the HTML file that loads the JavaScript game.
4. Open the HTML file in your browser.
5. Start playing when the prompt appears.

If the project uses a separate JavaScript file, ensure it is correctly linked to the HTML file.

## 🛠️ Technologies Used

- **JavaScript** — Implements the game logic, player input, AI choices, scoring, and round results.
- **HTML** — Provides the webpage that loads the game.
- **Browser APIs** — Uses prompts and alerts to interact with the player and display results.
