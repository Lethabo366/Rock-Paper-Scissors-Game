# Rock, Paper, Scissors

A browser-based Rock, Paper, Scissors game with a refreshed, interactive user
interface. Play against the computer, follow the score and round results on the
page, and restart whenever you like.

## Features

- Choose Rock, Paper, or Scissors with on-screen buttons.
- Play to **5 points**; draws do not award points.
- See both scores, each round's choices, and the result without opening the
  browser console.
- Buttons are disabled when the match ends to prevent extra rounds.
- Restart the game to reset the scores and play again.
- Responsive layout with a dark theme, hover and keyboard-focus states, and
  readable status updates for assistive technology.

## Rules

- Rock beats Scissors.
- Paper beats Rock.
- Scissors beats Paper.
- The first to 5 points wins. A draw does not change either score.
- The computer's move is selected randomly each round.

## Getting Started

### Play locally

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Select a move to play a round.

No dependencies, build step, or server are required.

### Project files

- `index.html` — Game layout and controls.
- `styles.css` — Responsive visual design and button states.
- `script.js` — Computer choices, round logic, scoring, and restart behavior.
